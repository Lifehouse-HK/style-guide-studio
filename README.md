# Style Guide Studio

Fresh implementation for Lifehouse Hong Kong's 夢幻團隊翻譯團隊, restarted on 2026-09-12. The discarded application remains only in Git history. MIT licensed.

The editor and portable domain/amendment/rendering modules are separate. The editor uses a document tree and fixed forms; amendments are generated from actions, never edited as ordinary documents. Development and verification status is recorded in [IMPLEMENTATION_PLAN.md](IMPLEMENTATION_PLAN.md). The [confirmed requirements and formula](docs/decisions/002-authoring-profile-and-enactment.md) remain the design source.

Commands: `npm install`, `npm run check`, `npm test`, `npm run build`, `npm run dev`. No deployment or document upload occurs automatically.
