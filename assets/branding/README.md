# Publication logo

`lifehouse-hong-kong-stacked.png` is the original, unmodified **Hong Kong - Stacked.png** supplied by the project owner from the church’s Hong Kong Logo asset folder on 2026-09-12.

- PNG, 751 × 610 pixels; 17,120 bytes.
- SHA-256: `04fc98ef842c4fb36880768ca341be306bd1e9acad509c1e70f8e44267845bc3`.
- No tracing, recolouring, cropping or regeneration.

The editor and PDF adapter embed this image as a data URL. The independent renderer receives it through `RenderOptions.logo`; it does not access the filesystem or Dropbox. The logo appears once above the titles, including one shared logo in the parallel layout. Its size is controlled centrally by `.publication-logo` in `modules/render.ts` (44 mm image width, original aspect ratio).
